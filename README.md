# Gyroflip

Gyroflip is a simple fluid simulation written in C using Raylib.
The ability to control the gravity with a gyro sensor is planned.

## To try

To run the program first make sure you have [Raylib installed](https://www.raylib.com/).
Run on Linux:
`cmake . && make && ./gyroflip`
To run on other platforms use the documentation provided by the [Raylib Wiki](https://github.com/raysan5/raylib/wiki) (under Developement Platforms).
